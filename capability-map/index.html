Hierarchical Accuracy

For each dataset, configuration accuracies are averaged within their shared backbone. Backbone scores are then averaged with equal backbone weight within each taxonomy group. The resulting group scores are averaged with equal dataset weight within the selected condition.

Reading guide

Methodology and privacy boundaries

Fixed result universe

The fixed core matches the Standard Overall leaderboard: 17 configurations across 8 backbones, each with complete 220 / 220 coverage.

Rank definition

Average Rank ranks the mutually exclusive groups within the active taxonomy on each dataset, using average ranks for exact ties.

Separate taxonomies

Evaluation Paradigm and Model Origin are separate taxonomies. Groups are mutually exclusive within each taxonomy and are never ranked across taxonomies.

Public data boundary

Only aggregate condition-level statistics are published. Dataset identities, source mappings, backbone names, and configuration names are excluded.

Models included in this analysis

The heatmap aggregates 17 configurations from these 8 backbones, each with results on all 220 datasets. Their model pages list the individual scores and classifier settings.

  • ChorusTIC classification results
  • Mantis classification results

The metric definitions explain accuracy and win counts. The aggregation method describes how classifier results contribute to a backbone score and then to a group score.

Average Group Rank compares groups within a taxonomy. For individual configurations, use the Standard Overall leaderboard and its ranking rules. The dataset profile gives the composition of the 220-dataset benchmark.
