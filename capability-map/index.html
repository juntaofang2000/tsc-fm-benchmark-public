Aggregate evidence

Condition-level detail

Every row is an aggregate; no dataset-level record is exposed or downloadable.

How Paradigm Accuracy is aggregated

For each dataset, Accuracy first averages all available method accuracies assigned to the paradigm or lens. These dataset-level scores are then averaged with equal dataset weight within the selected condition.

What W / T / L is relative to

W / T / L counts datasets where the paradigm- or lens-level score is uniquely best / tied for best / below the best among all displayed paradigms and lenses on that dataset. It is not a pairwise comparison against ChorusTIC or any fixed baseline; ties use a 1e-12 numerical tolerance.

Reading guide

Methodology and privacy boundaries

Unit and weighting

Dataset is the analysis unit. Each contributing dataset receives equal weight within its selected condition bin.

Missing results

Missing method–dataset results are excluded and are never replaced with zero.

Paradigm taxonomy

Decision-interface groups are mutually exclusive; model-origin lenses may overlap and are descriptive only.

Public data boundary

Only aggregate condition-level statistics are published. Dataset identities and source mappings are excluded.
