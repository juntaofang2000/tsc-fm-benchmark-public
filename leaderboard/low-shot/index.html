How the support sets are sampled

For each task and budget, the benchmark samples five or ten distinct examples per class from the original training split, using fixed support indices shared across configurations. A task qualifies only when every training class has enough examples. Models predict labels for the full original test split.

The eligible task pools differ across budgets. A change between column means therefore combines differences in label budget and task composition.
