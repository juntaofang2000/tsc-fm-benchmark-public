How ranking works. Average Accuracy is the unweighted mean across the eligible datasets shown by Coverage. Exact accuracy ties within 1e-12 receive average ranks. Low-shot budgets and modality scopes remain separate.

Read the complete ranking rules and reproducibility protocol. The release identifier above is a content fingerprint for the currently published public results.

How to compare time series classification foundation models

Start with Standard Overall to compare configurations covering all 220 datasets. Select Univariate or Multivariate when that matches your task. A model name can appear with several classifier heads: the head is part of the evaluated configuration, so the rankings compare complete prediction procedures.

Some models cover a narrower scope. TiCT and TimEE have results on all 140 univariate datasets under Standard evaluation. Select Standard Univariate to compare them with other models; neither has published Overall or Low-shot results here.

For few-shot time series classification, select Low-shot and then 5-shot or 10-shot. Compare models within the same budget and scope; dataset eligibility changes with the label budget. Average accuracy weights each eligible dataset equally, while average rank describes performance relative to the comparison set.

The leaderboard reports classification, where a sequence is assigned a class label. It does not rank time series forecasting models on future-value prediction. Inspect the model pages for checkpoints and configuration results before selecting a model.
