How are foundation models used for time series classification?

A time series foundation model (TSFM) learns reusable representations or prediction behavior during pretraining. Time series classification (TSC) assigns a class label to an input sequence. This benchmark compares how pretrained models transfer to classification through two approaches: in-context inference and frozen features with a classifier head.

A univariate sequence has one measured channel; a multivariate sequence has several. Check each model’s input type and the results for the relevant dataset scope before comparing scores. Catalog membership does not imply complete coverage of every evaluation setting.

In-context classification

These configurations predict from labeled context examples without fitting a classifier for each target dataset. The catalog includes time series models as well as TabICL and TabICLv2, tabular foundation models applied to vectorized time series.

  • ChorusTIC
  • TabICL
  • TabICLv2
  • TIC-FM
  • TiCT

Frozen representations and classifier heads

These configurations extract representations with a frozen pretrained encoder and use a downstream classifier. The classifier head is part of the evaluated configuration: two heads on the same backbone can produce different results.

  • Mantis
  • MantisV2
  • MOMENT
  • NuTime
  • UniShape

How to compare time series classification models

Use the time series classification leaderboard to compare average accuracy, average rank and dataset coverage under the same label budget and modality scope. The catalog groups classifier heads under one backbone; the leaderboard treats each evaluated configuration separately.

Standard evaluation uses the official training split. For limited-label comparisons, select Low-shot and then 5-shot or 10-shot. These settings use different feasible dataset subsets, so a higher score across settings does not by itself establish a better model. Read the few-shot classification protocol before interpreting the results.

Overall scores summarize performance across datasets. To investigate where models differ, use the capability analysis by dataset attributes, which evaluates its own fixed comparison core. Model detail pages provide configuration results and source references for further inspection.
