The second-generation TabICL foundation model applied to vectorized time series.

In this benchmark, TabICLv2 is evaluated using training-free in-context classification. Checkpoint information: tabicl-classifier-v2-20260212.ckpt. Check the results below for the settings and dataset scopes with published scores.

Compare accuracy and average rank only within the same evaluation setting and dataset scope. Standard uses the official training splits; 5-shot and 10-shot use different budget-feasible subsets. Rank and average rank include other models in the full comparison set. Scores are not averaged across configurations.

For comparisons with other backbones, open the foundation model classification leaderboard and use the same setting and scope. The few-shot evaluation protocol explains the label budgets.
