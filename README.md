# TSC-FM Benchmark: Time Series Classification Foundation Model Benchmark

This repository contains the sanitized, read-only static mirror of **TSC-FM Benchmark: Benchmarking Foundation Models for Time Series Classification**.

- [Official time series classification benchmark](https://tsc-fm.dmirlab.com/)
- [Time series classification leaderboard](https://tsc-fm.dmirlab.com/leaderboard)
- [Foundation models evaluated for time series classification](https://tsc-fm.dmirlab.com/methods)
- [Standard and few-shot evaluation protocol](https://tsc-fm.dmirlab.com/evaluation)
- Public content: aggregate benchmark composition, aggregate leaderboards, aggregate capability analysis, method summaries, and evaluation protocol
- Excluded content: source code, raw results, dataset identities, suite identities, source mappings, and generation history

The files in this repository are generated artifacts. Model submissions are handled by the [official TSC-FM Benchmark site](https://tsc-fm.dmirlab.com/submit).
