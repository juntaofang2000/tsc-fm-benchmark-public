# TSC-FM Benchmark Public Mirror

This repository contains the sanitized, read-only static export of the TSC-FM Benchmark website.

- Interactive site: https://tsc-fm-benchmark.vercel.app/
- Public content: aggregate benchmark composition, aggregate leaderboards, aggregate capability analysis, method summaries, and evaluation protocol
- Excluded content: source code, raw results, dataset identities, suite identities, source mappings, and generation history

The files in this repository are generated artifacts. Model submissions are handled by the interactive site.
